# Shadman Arko — portfolio

Live at **https://shadmanarko.github.io** · plain version at **/simple**.

A pixel-art portfolio built with [Astro](https://astro.build): a guided career tour from Dhaka to Berlin, AI work, all projects, experience, references and a printable CV.

- All content lives in `src/data/profile.json`.
- `src/components/tour/` is the career tour; `src/components/site/` is the rest of the page; `src/pages/simple.astro` is the plain one-page version.
- `npm install && npm run dev` to work locally; every push to `main` deploys to GitHub Pages via `.github/workflows/deploy.yml`.
